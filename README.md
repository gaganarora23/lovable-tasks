# Lovable Tasks

Create a Mini Kanban board. Mock the backend. I will create the fastapi backend service later on. 
I want to create a Project and create tasks under the Project. Add labels or custom tags to the task and assign priority. As of now I am only one but I can have multiple people in the team. I think there can be dashboard where tasks can be parked and moved to Todo/Complete. Ask questions if anything needs clarification.

This project was built with [Lovable](https://lovable.dev).
